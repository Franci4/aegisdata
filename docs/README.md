# 文档索引

本目录存放网站的文档与参考资料。**网站在运行时不依赖这里的任何文件**（单文件版已内联全部资源），这里只用于说明与交接。

| 路径 | 内容 | 用途 |
| --- | --- | --- |
| [PRD.md](PRD.md) | 产品需求文档 | 项目背景、目标用户、指标体系、Epics、系统架构 |
| [启动说明.md](启动说明.md) | 运行与演示说明 | 怎么打开、怎么演示、开发约定 |
| [screenshots/](screenshots/) | 网站截图 | 四个页面的成品截图，可直接用于汇报材料 |
| [materials/](materials/) | 原始参考素材 | 任务书截图、权限规则原始版本、原型图，用于追溯规则来源 |

## 建议的阅读顺序

1. **PRD.md** —— 先搞清楚要解决什么问题、交付什么
2. **启动说明.md** —— 怎么把页面跑起来、怎么给老师演示
3. **screenshots/** —— 看成品长什么样
4. **materials/** —— 需要追溯某条规则是怎么定的时候再翻
